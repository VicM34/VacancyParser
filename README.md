# VacancyParser - система поиска и сохранения вакансий с hh.ru

[![Python](https://img.shields.io/badge/Python-3.14-blue.svg)](https://www.python.org/)
Система для поиска вакансий с сайта hh.ru с возможностью сохранения в различных форматах (JSON, CSV, TXT) и фильтрации по заданным критериям.


## 🚀 Возможности
- 🔍 **Поиск вакансий** на hh.ru по ключевым словам
- 💾 **Сохранение в разных форматах**: JSON, CSV, TXT
- 🎯 **Фильтрация вакансий** по:
  - Ключевым словам в названии, описании или требованиях
  - Минимальной зарплате
- 📊 **Сравнение вакансий** по уровню зарплаты
- 🗑️ **Управление сохраненными вакансиями**: удаление, очистка
- ✅ **Автоматическое предотвращение дубликатов**

## 📊 Форматы сохранения

### JSON (рекомендуемый)
- **Преимущества:** Сохраняет полную структуру данных, легко читается программами
- **Файл:** `data/vacancies.json`
- **Структура:** Полные объекты вакансий со всеми полями

**Пример структуры JSON:**
```json
[
  {
    "title": "Python Developer",
    "url": "https://hh.ru/vacancy/123",
    "salary": {
      "from": 100000,
      "to": 150000,
      "currency": "RUR"
    },
    "description": "Разработка на Python",
    "requirements": "Опыт работы с Python от 3 лет",
    "avg_salary": 125000
  }
]
```
## 📊 Форматы сохранения

### CSV
- **Преимущества:** Удобен для импорта в табличные редакторы (Excel, Google Sheets)
- **Файл:** `data/vacancies.csv`
- **Поля:** `title`, `url`, `salary_from`, `salary_to`, `currency`, `description`, `requirements`, `avg_salary`

**Пример CSV файла:**
```csv
title,url,salary_from,salary_to,currency,description,requirements,avg_salary
Python Developer,https://hh.ru/vacancy/123,100000,150000,RUR,Разработка на Python,Опыт работы с Python от 3 лет,125000
Java Developer,https://hh.ru/vacancy/456,120000,180000,RUR,Разработка на Java,Опыт работы с Java от 2 лет,150000
Data Scientist,https://hh.ru/vacancy/789,150000,200000,RUR,Анализ данных,Знание Python и SQL,175000
```
### TXT
- **Преимущества:** Читаемый формат для человека
- **Файл:** `data/vacancies.txt`
- **Формат:** Отформатированный текст с разделителями

**Пример содержимого TXT файла:**
```
Вакансия: Python Developer
Зарплата: 100,000 - 150,000 RUR
Ссылка: https://hh.ru/vacancy/123
Описание: Разработка на Python
Требования: Опыт работы с Python от 3 лет
==================================================

Вакансия: Java Developer
Зарплата: 120,000 - 180,000 RUR
Ссылка: https://hh.ru/vacancy/456
Описание: Разработка на Java
Требования: Опыт работы с Java от 2 лет
==================================================
```
